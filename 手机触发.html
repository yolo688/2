连接设置

只存在这台手机的浏览器里，不会上传到别的地方。换手机或清缓存后要重新填。

填一次就好

第一次用，先做三件事

  1. 把 push.py 和 .github/workflows/daily-push.yml 传到你的私有仓库。
  2. 在仓库 Settings → Secrets and variables → Actions 里配好 5 个 Secret。
  3. 在 GitHub Settings → Developer settings → Personal access tokens → Fine-grained tokens 新建令牌，仓库只选这一个，权限勾上 Actions: Read and write，把生成的令牌填到上面。

在手机浏览器里打开后，用「添加到主屏幕」存成图标，下次一点就开。
